# Análise Transparente de Viagens Públicas

Este projeto explora dados de viagens financiadas com recursos públicos, com foco na análise do custo médio por viagem entre diferentes órgãos governamentais. A proposta é investigar padrões, identificar possíveis ineficiências e fomentar uma discussão técnica sobre a transparência e a gestão dos recursos públicos.

## Objetivo

Oferecer uma análise exploratória, com visualizações claras e embasamento estatístico, para evidenciar:
- A relação entre o número de viagens e os custos envolvidos.
- Órgãos com maiores custos médios por deslocamento.
- Casos onde o custo elevado não é acompanhado de justificativa transparente.

Este projeto **não tem viés político**. Seu objetivo é promover a cultura de dados abertos e contribuir para o debate público com base em evidências.

Fonte de dados: Portal da Transparência
